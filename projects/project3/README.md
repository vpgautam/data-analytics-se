# Project 3 — Multivariate Forecasting

**Status:** unlocked ✅

**Goal:** predict the next value of a target series (`A`) from **multiple input
features** (`A`, `B`, `C`) generated by a known ARX process, using proper
mini-batch training.

**New concepts:** `input_size > 1` (feature vectors per timestep), custom
`Dataset` + `DataLoader` mini-batching (and why shuffling *windows* is OK), and
a multivariate-vs-univariate payoff experiment on a dataset big enough to be
conclusive.
